# Student Management System - Spring Boot

A simple and user-friendly web application built using **Spring Boot**, **Thymeleaf**, and **Bootstrap** to perform CRUD (Create, Read, Update, Delete) operations on student records.

## 📌 Features

- 🧑 Add new students
- 📋 View all students
- ✏️ Update existing student details
- ❌ Delete students
- 💻 Frontend using Thymeleaf templates and Bootstrap 4
- 💾 Backend using Spring Boot and JPA (Hibernate)

## 🛠️ Tech Stack

- **Backend**: Java, Spring Boot, Spring MVC, Spring Data JPA
- **Frontend**: HTML, Thymeleaf, Bootstrap 4
- **Database**:  MySQL 
- **Build Tool**: Maven
